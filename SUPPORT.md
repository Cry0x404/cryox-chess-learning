# Support

Use GitHub Issues for reproducible defects, feature requests, and documentation problems.

Before opening an issue:

- verify the problem still occurs on the latest `main` branch or latest release;
- include the Python version and operating system;
- include the relevant configuration values;
- include a minimal reproduction when possible;
- remove secrets, private paths, and unrelated runtime data from logs.

Security-sensitive reports should follow `SECURITY.md` instead of being posted publicly.
