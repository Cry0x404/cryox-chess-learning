# Code of Conduct

## Our standard

Project spaces should remain professional, constructive, and focused on the work. Participants are expected to communicate respectfully, provide actionable technical feedback, and avoid harassment, threats, personal attacks, discriminatory conduct, or deliberate disruption.

## Scope

This standard applies to repository issues, pull requests, discussions, code review, and other project-managed spaces.

## Enforcement

Repository maintainers may edit, hide, lock, or remove content and may restrict participation when behavior repeatedly or seriously violates this standard.

For security-sensitive matters, use the process described in `SECURITY.md`.
